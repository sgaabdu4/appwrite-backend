# Appwrite Backend Skill

## Users

Developers using Claude Code or Codex to build applications with Appwrite.

## Problem

Agents need accurate Appwrite SDK patterns and operational safeguards before changing live projects, schema, access policies, functions, or credentials.

## Product Purpose

The skill supplies focused guidance for application SDK development and MCP-only agent operations. Its query helper and native contract tests preserve query behavior and safety instructions.

## Boundaries

This repository distributes a community skill, not an Appwrite deployment or application runtime. It owns `skills/appwrite-backend`; Hard Eng supplies repository engineering checks. Application SDK use remains supported. Agent operations require an authenticated MCP capability and exact project binding; unsupported operations stop with a stated capability gap.
